Did always-on make the Caveman skill run every time?

Yes. We proved it on this playground with a Caveman skill whose only job was: make the triage bot’s human-facing comment start with exactly CAVEMAN:.

Skill files on the agents proof branch: smoke-always-on (always-on) and smoke-listed (same Caveman rules, listed only). Both say “Caveman” in the body; the proof token is the CAVEMAN: first line.

What always-on means here: set metadata.apply: always on the Caveman skill, and before triage runs fill a placeholder in the agent prompt with that skill’s name so the model opens it with the Skill tool. We do not paste the skill body into the agent file.

The three setups

  1. Baseline — no Caveman skill. Control.
  2. Listed only — Caveman skill on harness skills:, no always-on flag. Same rules as always-on, but nothing tells the model it must open it.
  3. Always-on — same Caveman skill with metadata.apply: always + name in the prompt.

Three repeats each. Pass = triage comment starts with CAVEMAN:.
